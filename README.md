# صالون الربطة الوردية — بطاقة الخصومات

- `index.html#offers` — صفحة الخصومات اللي يفتحها الباركود المطبوع على البطاقة.
- `index.html#admin` — لوحة تعديل الخصومات (غيّري الرمز السري الافتراضي 1234).
- `index.html` — استوديو تصميم البطاقات وصانع الشعار.
- `config.json` — إعدادات صفحة الخصومات (العروض، الأكواد، الألوان، روابط التواصل).
