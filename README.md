# صالون الربطة الوردية — بطاقة الخصومات

| الصفحة | لمن | الوظيفة |
|---|---|---|
| `offers.html` | العميلات | صفحة الباركود: اختيار خصم واحد وإرسال القسيمة على الواتساب |
| `staff.html` | الاستقبال | التحقق من رقم القسيمة وتسجيلها كمستخدمة |
| `index.html` | الإدارة | استوديو تصميم البطاقات، صانع الشعار، ولوحة الخصومات (`#admin`) |
| `config.json` | — | العروض، الشروط، التواريخ، الألوان، روابط التواصل |
